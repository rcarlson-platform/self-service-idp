## Findings

1. **The commit author does not show who pushed.** The workflows set the author name with `git config`, so the commit shows `github-actions[bot]` even when the App pushed. The proof is the actor in the repository activity feed (`gh api 'repos/rcarlson-platform/self-service-idp/activity?ref=refs/heads/main'`).
2. **The Events API was not a usable check.** Its newest entry was hours old when queried, so the first attempt was inconclusive, not a pass.
3. **Package visibility (Observed, mechanism not verified).** With the org setting that allows public packages enabled, the tenant package took the visibility of its public repo. This contradicts the earlier statement that each package must be made public by hand. The setup document and R22 still carry the old statement and need correcting.
4. **`gh` lacks the `read:packages` scope**, so package checks through the API return HTTP 403. The UI was used instead.
